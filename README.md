# Module 03 — Web Application Security (Day 11–Day 15)

Intermediate learning project covering web fundamentals, OWASP Top 10:2025, authorized lab testing, vulnerability reporting and remediation.

## Daily plan
- Day 11: HTTP/HTTPS, requests/responses, cookies, sessions, authentication and authorization.
- Day 12: OWASP Top 10:2025 categories and prevention.
- Day 13: Safe local lab using OWASP Juice Shop.
- Day 14: OWASP analysis and vulnerability assessment report.
- Day 15: Remediation, retesting and final demonstration.

## Deliverables
Learning notes, lab observations, genuine screenshots, vulnerability report, remediation recommendations and LinkedIn post.

## Safety
Only test systems you own or have explicit permission to assess. Keep Juice Shop bound to localhost. Never publish passwords, tokens, cookies or personal information. Do not claim findings you have not verified.
